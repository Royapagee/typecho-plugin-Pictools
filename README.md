# Pictools —— Typecho 图片上传前简易编辑器

在后台撰写文章页面为图片附件提供 **裁剪、缩放、格式转换** 功能,选完图片即可编辑,确认后按原上传流程写入,无需任何后端配置。

## 功能特性

- **裁剪**:在预览画布上拖拽框选裁剪区域,带九宫格辅助线,支持一键重置;
- **缩放**:按百分比输出(1% ~ 200%),默认 100% 保持原图尺寸;
- **格式转换**:原始格式 / JPEG / PNG / WebP 自由切换,JPEG 与 WebP 输出质量为 0.92;
- **实时预览**:右侧同步显示缩放 / 裁剪后的输出预览与实际输出尺寸;
- **多文件排队**:连续选择多张图片时依次弹出编辑框,不会相互打断;
- **移动端友好**:支持触摸拖拽裁剪;
- **无侵入设计**:非图片文件原样走系统上传,完全不影响原有流程。

## 兼容性

| 项目 | 要求 |
| ------ | ------ |
| 系统 | Typecho 1.3.0(基于 `TypechoPlugin` 命名空间) |
| 语言 | PHP 7.4+(无需任何扩展) |
| 浏览器 | 支持 Canvas `toBlob` 与 `File` 构造函数的现代浏览器 |

编辑器为纯前端实现(`Canvas` + 原生 JS),不依赖 PHP 扩展,不写数据库,不新增配置项。

## 安装

1. 将本插件目录放入 `usr/plugins/Pictools`;
2. 登录后台 → **控制台 → 插件**,找到 **Pictools**,点击 **启用** 即可。

启用后,进入 **撰写文章** 页面上传图片,选中任意图片附件时会自动弹出编辑窗口。

## 使用方法

1. 在文章编辑页点击上传图片;
2. 图片文件自动弹出编辑框:
   - **裁剪**:在左侧画布上按下鼠标左键拖动,框选需要保留的区域(再次拖动可重新选择);
   - **缩放**:在顶部工具条输入输出比例(1 ~ 200);
   - **格式**:在顶部工具条选择输出格式(原始 / JPEG / PNG / WebP);
3. 右侧面板实时展示输出预览与尺寸信息;
4. 点击 **「确定并上传」** 完成上传(或 **「取消」** / 按 `Esc` 放弃);
5. 上传文件名会按所选格式自动更新扩展名(如 `photo.jpg` → `photo.webp`)。

## 工作原理

`Plugin.php` 通过 Hook 挂载到后台页面底部:

```php
\Typecho\Plugin::factory('admin/write-post.php')->bottom = __CLASS__ . '::render';
```

`render()` 注入 `pictools.css`、`pictools.js` 与初始化脚本,并在页面就绪后**拦截 `Typecho.uploadFile`**:当检测到 `file.type` 以 `image/` 开头时,改由 `Pictools.edit()` 打开编辑器;其余文件(含 GIF 动图等仍按图片处理的场景)直接交给原上传回调。确认编辑后,插件用 `Canvas.toBlob()` 生成新文件并回调原上传函数,上传逻辑完全复用系统默认实现。

> 若页面中不存在 jQuery 或 `Typecho.uploadFile`,脚本会安全返回,不影响站点其他功能。

## 目录结构

```text
Pictools/
├── Plugin.php              # 插件入口:挂载 Hook、注入资源与拦截脚本
└── static/
    ├── pictools.css        # 编辑弹窗样式(响应式、适配低高度窗口)
    └── pictools.js         # 编辑器核心:裁剪 / 缩放 / 格式转换 / 队列
```

## 已知限制

- 输出格式为 **WebP** 时需浏览器支持 `canvas.toBlob('image/webp')`(现代 Chrome / Edge / Firefox 均支持);
- 编辑仅作用于「上传前」的图片文件,不影响已上传附件的再编辑。
